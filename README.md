# Soap Slice

コード生成のマーブル石鹸と、小さな立方体の破片を楽しむブラウザASMRゲーム。Vite + TypeScript + Three.js。広告・課金・ログイン・外部API・外部フォント・音源ファイルはありません。

## ソースコード

[ixzaby-bot/soap-slice](https://github.com/ixzaby-bot/soap-slice)

```sh
git clone https://github.com/ixzaby-bot/soap-slice.git
cd soap-slice
```

リポジトリにはソース・テスト・仕様書・依存関係のロックファイルを含めます。`node_modules/`、`dist/`、検証用スクリーンショット、環境変数ファイルや秘密鍵はコミット対象外です。

## 起動

Node.js 22.12以上（テストは22.18以上、推奨24）を用意します。

```sh
npm install
npm run dev
```

表示されたローカルURLを開きます。同じWi-Fi上のiPhoneからは、PCのLAN IPと表示されたポート（例 `http://192.168.1.10:5173`）にアクセスできます。必要に応じてOSのファイアウォールで開発用ポートを許可してください。

```sh
npm test
npm run build
npm run preview
```

成果物は `dist/`。`file://`でHTMLを直接開かず、HTTPサーバーで配信してください。

## 操作

- 石鹸のエリアを下方向へドラッグ。iPhoneは指一本、PCはマウスで操作します。
- 指を離し、上からもう一度なぞると次のストローク。1回の切削は最大10.5%。静止・上方向の移動では削れません。
- 音は初期ONで、最初の操作から合成した削り音が鳴ります。「音」でON/OFFを切り替えられます。ONにすると短い確認音が鳴ります。音量・音色は刃の移動速度に連動します。
- 100%で金色の星と紙吹雪。「次の石鹸へ」で次の色に進みます。
- 「フリーモード」は削り切ると自動更新。「リセット」は現在の石鹸を最初に戻します。
- 対応スマホでは切削中に8msの短い振動を約95ms以上の間隔で入れます。指を離す・操作をキャンセルすると停止します。iPhone SafariはVibration API非対応のため、振動は鳴りません。代わりに刃の小さな動きで手応えを表現します（動きを減らす設定では抑制）。

## GitHub Pages

1. リポジトリへソースと `package-lock.json` を追加します。
2. `npm ci` → `npm run build` を実行します。
3. `dist/` の**中身**を公開用ブランチ（例 `gh-pages`）のルートに配置します。
4. GitHubの Settings → Pages で、そのブランチの `/ (root)` を公開元に指定します。

Viteの `base: './'` により、リポジトリ名のサブパスでも動作します。GitHub Actionsを使う場合も、ビルド後に `dist/` をPages用アーティファクトとしてアップロードしてください。

## オフライン

本番ビルドではService Workerを生成します。HTTPS（GitHub Pages）またはlocalhostで一度オンライン起動し、キャッシュ作成が完了すれば、以降は通信なしで再読み込みできます。初回のアクセス・キャッシュ消去後には通信が必要です。開発サーバーでは登録しません。iPhoneのストレージ管理によりキャッシュが削除される場合があります。

## 実装

- シード付きマーブル模様、ローズ・抹茶・ラベンダーの3種。削るほど低くなる表面と変化する縞。
- 接触線から生成するInstancedMeshの破片。400個固定プール、端末により初期240/400個、フレーム時間に応じ100〜400個へ調整。
- 重力・回転・石鹸/トレー/床との衝突・反発・摩擦・寿命末期の縮小消滅。更新時に破片オブジェクトは新規確保しません。
- Pointer Events、pointer capture、キャンセル/画面非表示時の音停止、セーフエリア・縦横レイアウト。
- Web Audioのループノイズをフィルタし、描画中の切削速度に同期して発音。初期ON、Safariの中断状態からの再開、対応環境でのplaybackセッション、音の開始失敗の案内を実装。
- 進捗・リセット・自由切削・金色の星・クリア時のみの紙吹雪。

## 制限と次の改善

任意形状のブーリアン切削ではなく、全体の高さを下げるMVP方式です。層は模様の移動で表現します。破片同士の衝突、半透明フェード、ナイフの種類、設定保存は未実装です。刃はフレーム時間に応じて滑らかに追従し、接触線から破片が発生します。次の改善候補は局所的な切削面と音の細かな粒感です。

実機iPhone Safariでの音・タッチ・画面回転と、30秒連続操作のフレーム時間/メモリを最終確認してください。デスクトップのモバイルエミュレーションは実機検証を代替しません。

## 検証記録

- TypeScriptチェック・Vite本番ビルド成功。Three.jsを含む約520 KBのJSにサイズ警告があります（gzip約135 KB、ビルドを妨げません）。
- `npm test`：6件成功（静止/逆方向、ストローク上限、イベント頻度、クリア/高さ、シード再現性、30/60/120fpsでの追従と削り量保存）。
- Edgeのヘッドレスブラウザ：390×844および1280×800で描画・進捗・音切替・クリア・次ステージ・フリーモード・リセットを確認、JavaScript実行時エラーなし。
- エミュレートしたタッチ入力と30秒/52ストロークの連続操作に成功。実機の60fpsや長期メモリ安定性を保証する測定ではありません。
- 本番版のキャッシュ作成後、ネットワークを切断して再読み込み・切削に成功。
- 音声信号の出力、切削停止後の無音、ミュート、中断後の再開、タッチ時の振動API呼び出し、フォーカス喪失時の切削/音停止をブラウザテストで確認。
- 実際の音の聴感・振動の強さ・iPhone Safari実機は未検証。

任意の追加ブラウザ検証は、PlaywrightとMicrosoft Edgeを用意して `node scripts/browser-check.mjs` で実行できます。既定は開発URL `http://127.0.0.1:5173`。`GAME_URL`を本番プレビューURLにするとオフライン検証も行います。既存のPlaywrightを使う場合は `PLAYWRIGHT_MODULE` にその `index.mjs` の絶対パスを指定できます。
